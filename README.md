# Website Desa - Sistem Administrasi Kependudukan

Website Desa modern dengan desain glassmorphism dan modul layanan kependudukan online.

## Struktur Proyek

```text
website-desa/
├── frontend/
│   ├── assets/
│   │   ├── css/
│   │   │   ├── glass-morphism.css
│   │   │   ├── style.css
│   │   │   └── responsive.css
│   │   ├── js/
│   │   │   └── main.js
│   │   └── img/
│   └── pages/
│       ├── index.html
│       ├── profil-desa.html
│       ├── administrasi.html
│       ├── pengajuan-surat.html
│       ├── cek-status.html
│       ├── berita.html
│       ├── galeri.html
│       ├── agenda.html
│       ├── kontak.html
│       └── login.html
├── database/
│   └── schema.sql
├── README.md
└── .gitignore
```

## Fitur Utama

- Profil desa dan visi misi
- Informasi berita, agenda, galeri
- Layanan administrasi kependudukan
- Pengajuan surat online
- Cek status surat
- Dashboard admin untuk verifikasi
- Desain glassmorphism modern

## Teknologi

- HTML5
- CSS3
- JavaScript
- MySQL

## Cara Menjalankan

1. Import database MySQL dari `database/schema.sql`
2. Buka `frontend/pages/index.html` di browser
3. Atau jalankan di server lokal untuk kompatibilitas routing

## Catatan

File ini merupakan struktur proyek awal dan template landing page yang siap dikembangkan lebih lanjut.
